# Balapan Mobil Vektor

Game balapan mobil di mana pemain menjawab soal matematika vektor untuk menambah kecepatan mobilnya. Dibuat dengan Python dan Pygame.

## Fitur
- Beberapa tingkat kesulitan
- Input nama pemain
- Hitung mundur sebelum balapan dimulai
- Mengubah kecepatan mobil berdasarkan ketepatan jawaban

## Cara Menjalankan
1. Install Python 3 dan Pygame:
```bash
   pip install pygame
```
2. Unduh repo ini, lalu jalankan:
```bash
   cd balapan-mobil-vektor
   python Game.py
```

## Yang Saya Pelajari
- Membuat game dengan Pygame: membuka jendela, memuat gambar, menggambar objek di layar, dan menjalankan game loop.
- Menyusun soal kuis dalam struktur data (pertanyaan, pilihan jawaban, kunci jawaban) yang dipisah per tingkat kesulitan, lalu menampilkannya secara acak.
- Menghubungkan jawaban pemain dengan mekanik permainan, yaitu jawaban benar menambah kecepatan mobil.
- Mengatur alur permainan seperti hitung mundur sebelum balapan dan input nama pemain.
- Menghitung jumlah putaran mobil sebagai win condition.
- Mengulang materi vektor dengan membuat soal-soalnya sendiri.
